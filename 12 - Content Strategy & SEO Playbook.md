# Document 12: Content Strategy & SEO Playbook

## DS Home Services

**Version:** 1.0  
**Status:** Approved  
**Priority:** Critical

## Purpose

This document defines the content strategy, information architecture, and SEO standards for the project.

The objective is not simply to rank higher in search engines.

The objective is to answer user intent better than competitors while maintaining a trustworthy and premium brand experience.

Every page should have a clear purpose for both users and search engines.

## SEO Philosophy

Write for people first.

Optimize for search engines second.

Never sacrifice readability for keywords.

Never create content only for ranking.

Trust is more valuable than traffic.

## Target Audience

### Primary Audience

- Homeowners
- Apartment owners
- Property managers
- Small businesses

### Typical User Intent

> “I need someone to fix something.”

> “I need help today.”

> “I need a reliable local professional.”

Content must answer these needs immediately.

## Content Pillars

The website should be organized around four content pillars.

### 1. Services

Explain every service clearly.

### 2. Service Areas

Show where the company works.

### 3. Trust

Reviews, process, guarantees, and portfolio.

### 4. Knowledge

Helpful articles answering common questions.

## Site Structure

- Homepage
- About
- Services
- Individual service pages
- Service areas
- Gallery
- Testimonials
- FAQ
- Contact
- Estimate request
- Blog
- Privacy Policy
- Terms of Service

## Service Page Template

Each service page should include:

- Headline
- Short introduction
- Benefits
- Common problems
- Our process
- Frequently asked questions
- Call to action
- Related services
- Service area information

## Local SEO

Every important city or town should have its own landing page.

Each page must contain:

- Unique introduction
- Services available
- Nearby areas
- Customer benefits
- Local references
- Internal links
- Unique metadata

Avoid duplicate content.

## Blog Strategy

The blog exists to educate and build trust.

Content categories:

- Home maintenance
- Electrical tips
- Plumbing tips
- Painting advice
- Furniture assembly
- Seasonal maintenance
- Safety tips
- Buying guides
- Preventive maintenance
- FAQ articles

## Content Quality

Every article should:

- Answer one primary question
- Be easy to read
- Use simple language
- Avoid unnecessary jargon
- Provide practical advice
- End with a relevant CTA

## Keyword Strategy

Each page targets:

- One primary keyword
- Two to five secondary keywords
- Natural language only

Never stuff keywords.

## Internal Linking

Every page should link naturally to:

- Related services
- Relevant blog articles
- Estimate page
- Contact page
- Service areas

Avoid orphan pages.

## Title Tags

Every page requires a unique title.

**Recommended length:** 50–60 characters

Include:

- Primary keyword
- Location, where appropriate
- Brand name

## Meta Descriptions

Every page requires a unique meta description.

**Recommended length:** 140–160 characters

Summarize the page.

Encourage clicks naturally.

## Headings

Use one H1 only.

Follow a logical hierarchy:

- H2
- H3
- H4

Never skip heading levels.

## Images

Every image must have:

- Descriptive filename
- Alt text
- Optimized size
- Lazy loading
- Modern format

## Structured Data

Implement structured data where appropriate.

Examples:

- Local Business
- Service
- FAQ
- Breadcrumb
- Article
- Review
- Organization

## Open Graph

Every page should include:

- Title
- Description
- Image
- URL
- Site name

## Technical SEO

Generate:

- XML sitemap
- `robots.txt`
- Canonical URLs
- 404 page
- Redirect strategy
- Clean URLs

## Performance and SEO

Fast websites rank better.

Targets:

- Largest Contentful Paint below 2.5 seconds
- Cumulative Layout Shift below 0.1
- Interaction to Next Paint below 200ms

Optimize assets continuously.

## Multilanguage Strategy

### Future Languages

- Italian
- English
- German

Each language must have:

- Native URLs
- Translated metadata
- Localized content
- No automatic machine translation in production

## Content Review

Before publishing, verify:

- [ ] Grammar
- [ ] Spelling
- [ ] Brand voice
- [ ] Accuracy
- [ ] Readability
- [ ] Internal links
- [ ] Metadata
- [ ] SEO checklist

## Measurement

Track:

- Organic traffic
- Conversions
- Contact form submissions
- Estimate requests
- Top landing pages
- Bounce rate
- Average engagement time
- Search queries

Review data regularly and improve content.

## Final Principle

Every page should deserve to rank.

Every article should genuinely help someone.

Every piece of content should increase trust, answer a real question, and guide the visitor toward contacting the company.
