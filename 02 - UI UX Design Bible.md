# Document 02: UI/UX Design Bible

## DS Home Services

**Version:** 1.0  
**Status:** Approved  
**Priority:** Critical

## Purpose

This document defines the complete visual language of the project.

Every page, component, and interaction must follow these design principles.

Never create new visual styles unless explicitly instructed.

Consistency is more important than creativity.

## Design Philosophy

The website should feel like a premium technology product.

Not a construction company.

Not a local contractor.

Not a marketplace.

The feeling should be:

- Apple
- Linear
- Stripe
- Framer
- Airbnb
- Vercel

Modern.

Minimal.

Elegant.

Premium.

Timeless.

## Visual Emotion

The user should immediately feel:

- Trust
- Calm
- Professionalism
- Simplicity
- Speed
- Precision

Everything should feel expensive without looking luxurious.

Never flashy.

Never noisy.

Never cluttered.

## Layout System

Use a clean modern layout.

Large white spaces.

Perfect alignment.

Balanced composition.

Never overcrowd sections.

Each section should breathe.

**Maximum content width:** 1280px  
**Preferred content width:** 1200px

Use large spacing between sections:

- **Desktop:** 120–180px
- **Tablet:** 90–120px
- **Mobile:** 60–90px

## Grid

Use a modern responsive grid:

- 12-column desktop grid
- 8-column tablet grid
- 4-column mobile grid

Always align components.

Avoid random positioning.

## Typography

Typography is the most important design element.

Headlines should be large.

Simple.

Confident.

Readable.

### Recommended Scale

- **Hero titles:** 64–88px
- **Section titles:** 40–56px
- **Subtitles:** 24–32px
- **Body:** 18–20px
- **Small labels:** 14–16px

Use strong hierarchy.

Never overload text.

## Text Principles

- Short paragraphs
- Short headlines
- Few words
- Maximum clarity
- Avoid marketing clichés
- Every sentence must have purpose

## Color System

Temporary palette:

- **Primary:** White
- **Secondary:** Black
- **Neutral:** Gray
- **Neutral light:** Light gray
- **Accent:** Orange

Use color sparingly.

White space should dominate.

Never create colorful sections.

## Border Radius

Use modern rounded corners:

- **Cards:** 20–28px
- **Buttons:** 16–20px
- **Inputs:** 16px
- **Badges:** 999px

Consistency is mandatory.

## Shadows

Soft.

Elegant.

Large blur.

Low opacity.

Never use harsh shadows.

Never create floating effects that feel unrealistic.

## Buttons

Buttons must feel premium.

Large.

Comfortable.

Rounded.

### Primary Button

Solid.

### Secondary Button

Outline.

### Hover

Lift slightly.

Shadow increases.

### Transition

200–300ms.

Never use aggressive hover animations.

## Icons

Use clean line icons.

Use a consistent stroke width.

Use a minimal style.

Never mix icon packs.

## Cards

Cards should feel lightweight.

Large padding.

Rounded corners.

Soft shadows.

No borders unless necessary.

### Hover

- Slight elevation
- Small scale
- Soft shadow increase

## Animations

Motion should feel like Apple.

Subtle.

Elegant.

Purposeful.

Use:

- Fade
- Translate
- Scale
- Blur
- Spring motion

Never use:

- Bounce
- Flash
- Shake
- Spin
- Heavy parallax

Animation should guide attention.

Never distract.

## Scroll Experience

Scrolling should feel smooth.

Sections appear naturally.

No sudden movement.

Use staggered animations.

Content enters gracefully.

## Hero Section

The Hero is the most important section.

Use a split layout.

### Left Side

- Headline
- Description
- CTA buttons
- Trust indicators

### Right Side

- Premium interactive 3D house

The house is the centerpiece.

It replaces the traditional handyman photo.

## Interactive House

The house should feel alive.

Hover over rooms.

Soft glow.

Floating labels.

Examples:

- Electrical
- Painting
- Kitchen
- Furniture
- Doors
- TV
- Bathroom

Each hotspot reveals the corresponding service.

No navigation yet.

Only interaction.

## Trust Elements

Trust should be visible but subtle.

Possible elements:

- Years of experience
- Same-day service
- Fast response
- Professional team
- Verified reviews

Avoid fake-looking trust badges.

## Images

Avoid stock photography whenever possible.

Prefer:

- 3D
- Illustrations
- Real company photography
- Architectural renders

Premium visuals only.

## Whitespace

Whitespace is part of the design.

Never fill empty space without reason.

Large margins create a premium feeling.

## Responsiveness

Every section must be designed independently for:

- Desktop
- Tablet
- Mobile

Not simply resized.

Layouts may change.

Hierarchy must remain.

## Microinteractions

Buttons react.

Cards react.

Navigation reacts.

The house reacts.

Nothing feels static.

Everything responds subtly.

## Accessibility

- Readable contrast
- Large touch targets
- Keyboard navigation
- Visible focus states
- Semantic structure

## Consistency

Every page should feel like it belongs to the same product.

Never invent a different style for a new section.

The design language must remain identical across the entire website.

## Final Design Goal

The visitor should think:

> “This feels more like a modern tech company than a handyman business.”

The website should become one of the strongest competitive advantages of the company.

Every pixel should reinforce trust, speed, and simplicity.
